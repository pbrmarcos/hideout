Your passwords only unlock on your computer. No server sees a thing.

Hideout has no server and needs no online account. It only goes online to look for new versions on GitHub, which you can turn off, and for the leak check, when you ask for it. No password leaves your PC. The vault is an encrypted file. If it sits in OneDrive, the default, the cloud only stores scrambled bytes.

  • Master password becomes the key through scrypt, which makes mass guessing slow and expensive.
  • 2FA with an authenticator app when you sign in on a new computer.
  • 6-digit PIN for everyday use, protected by Windows. Five wrong tries ask for the password.
  • Copied, then gone: the password leaves the clipboard after 30 seconds and skips Win+V history.
  • Open source: anyone can check what the app does.
  • Leak check: see whether any of your passwords showed up in known breaches. Only 5 characters of a hash leave your PC, never the password.

Frequently asked questions

I forgot my master password. Now what?

Use the 24-character recovery code Hideout shows you once, when you create your account. It lets you set a new password, and it also works if you lose your 2FA phone. Without the password and the code, nobody can open the vault, not even the developer.

Do I need OneDrive? Does it work on more than one PC?

No. By default the vault lives in a Hideout-Dados folder in OneDrive, but you can pick any folder. With OneDrive, the same vault opens on another PC with your username, master password and 2FA.

Can I bring my browser passwords?

Yes. Export the passwords CSV from Chrome, Edge or Brave and use Importar do navegador (Import from browser) in the Acessos tab. Then delete the CSV, since it is not encrypted.

Why does Windows warn me when installing?

The installer has no code-signing certificate yet, and those cost money. Click More info, then Run anyway. The full code is on GitHub.

How do I know it is safe?

The code is open source (MIT) and anyone can check it. There is no server and no telemetry. The encryption, AES-256-GCM with an scrypt-derived key, lives in src/main/crypto.ts. Hideout has not had an independent audit yet.

Does Hideout update itself?

Yes. When it opens and once a day, it looks for new versions on GitHub, downloads them in the background and asks to restart. You can turn this off in Settings → Data. The portable version only tells you and opens the download page.
